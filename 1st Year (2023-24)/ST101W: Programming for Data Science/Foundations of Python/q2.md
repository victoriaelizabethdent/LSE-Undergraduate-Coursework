## Data Description

In this question, we will work on a modified set of movie data downloaded from Kaggle. Note the dataset also contain shows, but for the problem set we will treat all of them as movies.

Data is stored in [`data/movies.csv`](data/movies.csv). Each row (except the first row) represents the details of the participation of each actor/director in a movie in the following form:

```
<person id>,<person name>,<character(s)in the movie>,<role in the movie>,<movie id>,<move name>
```

Example rows:

```
3748,Robert De Niro,Travis Bickle,ACTOR,tm84618,Taxi Driver
14658,Jodie Foster,Iris Steensma,ACTOR,tm84618,Taxi Driver
20935,Victor Argo,"Melio, Delicatessen Owner",ACTOR,tm84618,Taxi Driver
17727,John Boorman,,DIRECTOR,tm154986,Deliverance
```

The role in the movie is either "ACTOR" or "DIRECTOR". There is only 1 row for each specific combination of an actor and a movie. For example, there is only one row with "Robert De Niro" as an actor in the movie "Taxi Driver"

- b. Repeat part (a), but this time create the variable `actor_to_movies_list` and use it to keep track of and store the result. It is a `list` of `list` like the following (may be displayed in one line instead of multiple lines):

- c. Comparing the approaches used in parts (a) and (b), which approach is more appropriate? State your reasons by considering:

  - What kind of data `dict` and `list` is designed for
  - Which container provides more easy-to-use functionality for the problem at hand
  - Which one is faster to complete the task

  Please write your textual answers below, and please keep the justifications in not more than 6 sentences:

  - Which approach is more appropriate? **The approach using 'dict' was more appropriate to complete the task.**
  - Justifications: **The 'dict' function organizes data into key-value pairs, making it particularly suitable for visualising the actor and the corresponding list of movies they have starred in. Using 'list' poses readability challenges as it seperates actor ID's and their corresponding movie lists into different nested lists, often of varying lengths, making associating the movies with the corresponding actor quite difficult. Furthermore, accessing the elements in a 'dict' is quite straightforward by using the actor key and directly retrieving the list of movies as the values, whereas in a list, knowing the index number for both the actor ID as well as the movie list is required in order to retrieve information about a particular one. Lists also permit duplicates while dictionaries do not, increasing the likelihood of errors when filtering and compiling a list of actors or actor ID's.**
