## Instructions

1. (6 marks) In `src/util.py`, write the function definition for the function `count_items_per_key()`. It takes a dictionary as an argument, with the value of each pair a `list`. The function returns another dictionary, for which each key is the same as the keys of the given dictionary, but the corresponding value is the lengths of the corresponding `list`. The given dictionary should not be altered

   - Example function call and return value:

   ```
   >>> count_items_per_key({'a': [1, 2, 3], 'b': [None]})
   {'a': 3, 'b': 1}
   ```

   Explanations:

   - the return value is a dictionary
   - the keys of the resulting dictionary are the same as the keys in the given dictionary (`'a'` and `'b'`)
   - for the key `'a'`: length of `[1, 2, 3]` is `3`
   - for the key `'b'`: length of `[None]` is `1`

2. (7 marks) Ensure the function `count_items_per_key()` works as intended by testing the function in [src/test_util.py](src/test_util.py)

   - At least 4 cases are expected
   - Please read the `Requirements on Testing` section for the requirements of the tests

3. (7 marks) In `src/util.py`, write the function definition for the function `get_occurrence_per_value()`. It takes a dictionary as an argument, with the value of each pair must be immutable. The function counts the occurrence of each value in the dictionary, and returns another dictionary, with keys representing the values it is counting, the values representing the number of occurrences of each value. The given dictionary should not be altered

   - Example function call and return value:

   ```
   >>> get_occurrence_per_value({'a': 1, 'b': ('1', '2'), 'c': 1})
   {1: 2, ('1', '2'): 1}
   ```

   Explanations:

   - For the given dictionary, `1` occurs twice as a value (one with `'a'`, another with `'c'`) and `('1', '2')` occurs once as a value

4. (8 marks) Ensure the function `get_occurrence_per_value()` works as intended by testing the function in [src/test_util.py](src/test_util.py)

   - At least 5 cases are expected
   - Please read the `Requirements on testing` section for the requirements of the tests

5. (5 marks) In `src/util.py`, write the function definition for the function `filter_with_values_gt()`. It takes a dictionary as the first argument, with the value of each pair must be a non-negative integer. It takes a non-negative integer as the second argument, for which it represents a threshold. The function returns another dictionary for which it contains all the pairs from the given dictionary that have the value greater than the threshold. The given dictionary should not be altered

   - Example function call and return value:

   ```
   >>> filter_with_values_gt({'a': 3, 'b': 2, 'c': 1}, 2)
   {'a': 3}
   ```

   Explanations:

   - Only the value 3 exceeds the threshold 2

6. (7 marks) Ensure the function `filter_with_values_gt()` works as intended by testing the function in [src/test_util.py](src/test_util.py)
   - At least 4 cases are expected
   - Please read the `Requirements on testing` section for the requirements of the tests
